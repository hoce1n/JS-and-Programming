# چرا به State نیاز داریم؟

## Problem

محاسبات متوالی باید بتوانند اطلاعاتی از گذشته را به آینده منتقل کنند. اگر هیچ Stateای نداشته باشیم،
هر دستورالعمل عملاً مستقل از گذشته می‌شود و محاسبات چندمرحله‌ای نمی‌توانند به نتایج قبلی وابسته
باشند.

## Computational Need

رایانه باید بتواند نتیجه‌ی یک مرحله را حفظ کند تا مرحله‌های بعدی بتوانند از آن استفاده کنند. بدون
این قابلیت، قدرت محاسبات به عملیات مستقل و بدون تاریخچه محدود می‌شود.

## Concept

**State** اطلاعاتی است که نتیجه یا وضعیت فعلیِ گذشته را برای استفاده در آینده نگه می‌دارد. به‌صورت
مفهومی، مسیر محاسبه چنین است:

```text
Past
  ↓
Current State
  ↓
Future Computation
```

پس State پلی میان گذشته، وضعیت فعلی سیستم و محاسبه‌ی آینده است.

## Language Feature

در JavaScript، State می‌تواند در مقادیر، Bindingها، Objectها، Arrayها، محیط‌های واژگانی و ساختارهای
اجرایی Runtime نمایان شود. متغیر فقط یکی از ابزارهای زبانی برای مدیریت بخشی از State است؛ خود مفهوم
State از متغیر بنیادی‌تر است.

## Syntax

این مثال نتیجه‌ی یک مرحله را برای استفاده در مرحله‌ی بعد نگه می‌دارد:

```js
let total = 10;
total = total + 5;

console.log(total); // 15
```

برای متغیر.
