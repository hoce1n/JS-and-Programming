# State مفهومی عمیق‌تر از Variable است

## Problem

اگر State را با Variable یکی بدانیم، مدل ذهنی ما فقط به Syntax زبان محدود می‌شود و نمی‌توانیم وضعیت
کل سیستم را توضیح دهیم.

## Computational Need

برای فهم اجرای برنامه، باید بتوانیم وضعیت فعلی سیستم را در سطوح مختلف توصیف کنیم؛ از سخت‌افزار و
Runtime گرفته تا داده‌هایی که برنامه مستقیماً با آن‌ها کار می‌کند.

## Concept

State یعنی اطلاعاتی که وضعیت فعلی یک سیستم را توصیف می‌کند. این مفهوم فقط به یک مقدار نام‌گذاری‌شده
در کد محدود نیست.

برای نمونه، CPU خودش State دارد: Registerها، Program Counter، Flagها و موارد دیگر. یک برنامه نیز
State دارد: Variableها، Objectها، Arrayها، Call Stack و ساختارهای اجرایی دیگر. حتی یک سیستم‌عامل نیز
State دارد.

بنابراین **State مفهومی بنیادی‌تر از Variable است** و Variable فقط یکی از ابزارهای مدیریت بخشی از
State محسوب می‌شود.

## Language Feature

JavaScript بخشی از State را با Bindingها و مقدارهایی که به آن‌ها متصل هستند مدل می‌کند. علاوه بر آن،
Runtime وضعیت‌هایی مانند Call Stack و محیط‌های واژگانی را نیز در زمان اجرا مدیریت می‌کند.

## Syntax

```js
let x = 10;
```

`x` یک Binding در زبان است که در حال حاضر به مقدار `10` مرتبط شده است. این خط فقط بخشی از State
برنامه را نشان می‌دهد، نه تمام State آن را.
